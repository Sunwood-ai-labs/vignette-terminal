# Vignette Terminal v0.1.0

Vignette Terminal v0.1.0 は、このアプリの最初の公開リリースです。Tauri 製のデスクトップターミナルに、シネマティックな動画背景、ランダム再生、透明な xterm.js のコマンド画面を組み合わせています。

## ハイライト

- `portable-pty` による実 PTY ターミナル。Windows では `cmd.exe` を既定シェルとして起動。
- `src/assets/media` に同梱した 5 本の MP4 背景動画。
- ランダムな背景動画再生と、ガード付きのクロスフェード切り替え。
- Tauri dialog plugin によるローカル画像・動画の選択。
- フレームレスウィンドウ、独自コントロール、ドラッグ可能な上部バー。
- 小さい OS 表示でも読みやすい、シンプルなアプリアイコンと favicon。
- CI、GitHub Pages docs、クロスプラットフォーム release build の GitHub Actions。

## ターミナル体験

フロントエンドは xterm.js を使い、透明な canvas でコマンド画面を描画します。背景の動画を見せつつ、ターミナルとしての読みやすさを保つ構成です。Rust 側は native PTY を開き、出力を Tauri event としてフロントに流し、ユーザー入力を PTY に書き戻します。ウィンドウサイズ変更時には PTY サイズも更新します。

## 背景メディア

既定のプレイリストは `src/assets/media` から同梱されます。起動時にランダムな動画から始まり、複数動画がある場合は直前と同じ index を避けます。現在の動画が終わる前に次の動画を準備し、再生可能になったら 1.6 秒の opacity transition で重ねて切り替えます。

## 配布

`v*` タグを push すると、`Release Builds` workflow が Windows、Linux、macOS で Tauri bundle を生成し、GitHub Release に添付します。

## 検証

- `npm run build`
- `npm run docs:build`
- `npm run tauri build`
